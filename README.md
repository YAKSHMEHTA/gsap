🚀 Learning GSAP

A collection of experiments and mini-projects while learning GSAP (GreenSock Animation Platform).
This repo showcases smooth animations, scroll effects, and interactive UI built using modern frontend tools.

---

🌐 Live Demo

🔗 https://gsap-eight-psi.vercel.app

---

📌 What This Project Covers

- Basic GSAP animations ("to", "from", "fromTo")
- Scroll-based animations using ScrollTrigger
- Smooth scrolling integration (Lenis)
- Timeline-based animation sequencing
- Practical UI animation experiments

---

🛠️ Tech Stack

- JavaScript (ES6+)
- React
- GSAP
- ScrollTrigger
- Lenis (for smooth scrolling)

---

📂 Project Structure

/SCT   → Scroll-trigger based animations
/ani   → Basic animation experiments

---

⚡ Getting Started

Clone the repo:

git clone https://github.com/YAKSHMEHTA/gsap.git
cd gsap

Install dependencies:

npm install

Run locally:

npm run dev
